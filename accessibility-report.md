
# Accessibility Audit Report

## Experiment
Hospital Patient Appointment Management Website

## Before Refactoring
- Excessive use of div elements.
- Improper heading structure.
- Form inputs without proper labels.
- Incorrect input types.
- No proper form validation.
- Limited accessibility support.

## After Refactoring
- Used HTML5 semantic elements.
- Organized headings properly.
- Added labels to all form inputs.
- Used appropriate input types.
- Implemented required field validation.
- Improved keyboard navigation.
- Added visible focus indicators.
- Tested using a screen reader.
