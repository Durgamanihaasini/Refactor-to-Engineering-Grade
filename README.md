
# Hospital Patient Appointment Management Website

## Experiment
Lab Experiment 2 – Refactor to Engineering-Grade HTML (M1)

## Objective
To improve webpage structure using HTML5 semantic
elements and make the patient appointment form accessible.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub

## Features
- Semantic HTML structure
- Hospital services section
- Doctor information section
- Accessible appointment form
- Form validation
- Keyboard navigation
- Responsive design

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Accessibility Testing
Before-and-after Lighthouse audits,
keyboard testing and screen-reader testing
were performed.

## Conclusion
The webpage was successfully refactored to
improve its structure and accessibility.
